# Отчёт: Уведомления в теме classiadspro

## 1. PUSH-УВЕДОМЛЕНИЯ (Firebase / FCM)

### Архитектура

Push-уведомления реализованы через плагин `firebase-push-notifications`.  
Тема вызывает хелпер-функцию `fpn_send_push($user_id, $data)`, которую предоставляет плагин.  
Все хуки темы сосредоточены в одном файле-обёртке.

---

### Место 1 — Новое личное сообщение

| Параметр       | Значение |
|----------------|----------|
| **Файл**       | `includes/actions/firebase.php`, строки 18–147 |
| **Функция**    | `classiadspro_firebase_message_sent()` |
| **Хук**        | `difp_action_message_after_send` (приоритет 10, 3 аргумента) |
| **Получатель** | Собеседник (не отправитель), определяется из `message_to_id` или мета-поля `_difp_participants` |
| **Заголовок**  | `"New message from {sender_name}"` |
| **Тело**       | Первые 20 слов текста сообщения |
| **action_url** | `/my-dashboard/?directory_action=messages&difpaction=viewmessage&difp_id={id}` |
| **notification_type** | `new_message` |
| **Статус**     | Активно |

## 2. EMAIL-УВЕДОМЛЕНИЯ

### Общее

- HTML-письма включены через фильтр `wp_mail_content_type` → функция `wpmail_content_type()` (`functions.php`, строка ~495)
- Отправитель: `admin_email` из настроек WordPress
- Для локальной разработки есть заготовка Mailtrap (закомментирована, строка 611)

---

### Место 1 — Приветственное письмо новому пользователю

| Параметр       | Значение |
|----------------|----------|
| **Файл**       | `functions.php`, строки 865–988 |
| **Функция**    | `classiadspro_send_welcome_email()` |
| **Хук**        | `wpfb_form_register_new_user_success` (приоритет 15) |
| **Получатель** | Email нового пользователя |
| **Тема письма** | Берётся из настроек темы, дефолт: `"Welcome to {site_name}!"` |
| **Содержание** | HTML-шаблон с кнопкой «Go to Your Dashboard», настраивается через панель темы |
| **Переменные** | `{user_name}`, `{site_name}`, `{site_url}`, `{dashboard_url}` |
| **Статус**     | Активно |

---

### Место 2 — Письмо о верификации аккаунта

| Параметр       | Значение |
|----------------|----------|
| **Файл**       | `functions.php`, строки 1450–1563 |
| **Функция**    | `classiadspro_send_verification_email()` |
| **Хук**        | Вызывается из `classiadspro_admin_save_verification_field()` при смене статуса на «верифицирован» |
| **Триггер-хуки** | `personal_options_update`, `edit_user_profile_update` |
| **Получатель** | Email пользователя |
| **Тема письма** | Из настроек темы, дефолт: `"Your Account Has Been Verified - {site_name}"` |
| **Содержание** | HTML-шаблон с зелёным заголовком «Account Verified!», список возможностей, кнопка «Go to Your Dashboard» |
| **Переменные** | `{user_name}`, `{site_name}`, `{site_url}`, `{dashboard_url}` |
| **Статус**     | Активно |

---

### Место 3 — Письмо об окончании платного рекламирования

| Параметр       | Значение |
